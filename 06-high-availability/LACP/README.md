# Cisco LACP EtherChannel Lab

This lab demonstrates a **real-world Cisco LACP (Link Aggregation Control Protocol)** configuration using EtherChannel (Port-Channel). The lab simulates an enterprise-grade network design suitable for **data center, campus, and dual-ISP redundancy environments**.

---

## 📌 Project Overview

This lab focuses on:

- LACP EtherChannel configuration (IEEE 802.3ad standard)
- Port-channel interface creation and management
- Switch-to-switch link aggregation
- Load balancing across multiple physical links
- Redundancy and failover behavior
- Verification and troubleshooting commands

---

## 🧠 Key Concepts

- **LACP (Active/Passive mode)** for dynamic link aggregation
- **EtherChannel / Port-Channel** logical interface
- **Load balancing across physical links**
- **STP treats Port-Channel as a single link**
- Prevents loops while increasing bandwidth
